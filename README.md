# Fei Yang

I explore machine economics and autonomous AI research: how AI changes production and capital formation, and what makes machine-generated research trustworthy.

## Research interests

- **Machine economics:** AI as a production factor, autonomous economic agents, and the roles of compute, energy, physical scarcity, and capital.
- **Autonomous AI research:** exploration, experiment design, evaluation, reproducibility, and failure modes in long-running research systems.
- **Verification:** tests and evidence that help distinguish a plausible result from a result others can independently check.

I value small, reproducible contributions to concrete problems: negative controls, minimal reproductions, code fixes, and careful methodological questions. I use AI tools in research and development, and aim to make methods, limitations, and relevant tool use clear.

## Earlier work

My earlier GitHub work used the name **Invaribreak** and focused on Web3 and AI security, including failure structures, authorization, and execution boundaries. That history remains part of this account.
